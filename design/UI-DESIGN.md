# ArrowMind UI design v7 — selected palette A with real recognition video

## Hard constraints

Use only owner-supplied App Store artwork and frames from the supplied English launch film for ALL app UI, phones, charts and detail panels. Do not redraw screens, synthesize points/scores, generate phone imagery, stretch tablet screenshots into phones, or create missing interfaces. Crop only complete relevant source panels, preserve proportions, keep source pixels. Decorative website icons and framing are separate from product UI. No iPads, gradients or dark page sections.

## Reference and structure

Apifox (https://apifox.com/) was inspected in-browser: a function index leads into paired feature explanations and real product views; changing a feature explanation changes the visual. Apply that structure to seven ArrowMind chapters, using original film/App Store copy. Use the approved platinum/cobalt palette, store download links, global/language facts and approved sample community wall.

Each chapter: numbered category, benefit headline, two or three selectable explanations, corresponding real screenshot/film frame and a magnified source detail card. Desktop alternates copy and product panels; mobile puts copy above full-width images and places detail cards below the main visual. Never hide important UI under a floating card. Transitions animate the original image layer only.
